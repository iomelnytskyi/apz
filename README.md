## Про репозиторій

Цей репозиторій містить результати виконання п'яти практичних робіт із дисципліни «Аналіз програмного забезпечення». У процесі роботи було опрацьовано основи електронного документообігу, системи контролю версій Git, методи тестування програмного забезпечення та можливості хмарних сервісів Amazon Web Services (AWS).

## Виконані практичні роботи

### Практична робота №1. Кваліфікований електронний підпис (КЕП)

Ознайомилися з принципами використання кваліфікованого електронного підпису для роботи з цифровими документами. Навчилися підписувати PDF-документи, перевіряти електронний підпис та розуміти його значення для безпечного електронного документообігу.

### Практична робота №2. Git і GitHub

Опанували базові принципи роботи із системою контролю версій Git і платформою GitHub. Створили власний репозиторій `apz`, організували структуру папок для практичних робіт та навчилися завантажувати й упорядковувати навчальні матеріали.

### Практична робота №3. Розроблення тест-кейсів

Дослідили основні принципи тестування якості програмних і технічних продуктів. На прикладі смартфона розробили 10 тест-кейсів із визначенням передумов, кроків виконання та очікуваних результатів. Отримали навички систематизації перевірок і формування тестової документації.

### Практична робота №4. Amazon S3

Ознайомилися з можливостями хмарного сховища Amazon S3. Створили персональну HTML-сторінку, опрацювали створення бакета, завантаження файлів та налаштування публічного доступу. Навчилися використовувати хмарне середовище для розміщення статичних вебсторінок.

### Практична робота №5. Amazon EC2

Дослідили можливості хмарних обчислень за допомогою Amazon EC2. Опрацювали створення Windows-віртуальної машини, налаштування її параметрів та віддалене підключення через RDP. Отримали базові навички адміністрування віртуальних машин у хмарному середовищі.

## Загальний висновок

У результаті виконання практичних робіт було закріплено теоретичні знання та сформовано базові практичні навички використання сучасних інструментів розроблення, тестування й адміністрування програмного забезпечення.

Особливу увагу приділено роботі з GitHub, створенню тестової документації, використанню електронного підпису та ознайомленню з хмарною інфраструктурою AWS.

Отриманий досвід є основою для подальшого професійного розвитку у сфері інформаційних технологій, забезпечення якості програмного забезпечення та хмарних обчислень.
